搭建指南

从零到上线：静态站 3 分钟，Docker 版 5 分钟，专业版解压即用。

方式一：静态站（免费）

适合公开文档、产品手册、个人知识库。

1

Fork 模板

fork TanchiPanda/r6t5-docs-community，把仓库名改成你的站点名。

2

替换内容

把 docs/ 里的 Markdown 换成你的；在 manifest.json 里登记目录与文件路径。

3

开启 Pages

Settings → Pages → Source 选 main / root，保存后访问 https://<用户名>.github.io/<仓库名>/。

静态版是纯前端渲染：搜索索引在浏览器里按 manifest 建立，锁定只是视觉截断，源文件仍可下载。要真正防抓原文，用 Docker 版。

方式二：专业版 zip

已经有分发包时，解压即用，不需要服务器。

解压后目录里通常包含 index.html、manifest.json、docs/、sql/。把整目录上传到任意静态托管（GitHub Pages、Cloudflare Pages、Vercel、对象存储）即可。

想开积分 / VIP：在 manifest.json 的 points 里填 Supabase URL 与 anon key，再在 Supabase SQL Editor 执行 sql/points.sql 与 sql/points_v2.sql。

方式三：Docker 自托管

带管理后台、服务端截断、积分与 VIP 的完整版。

一条命令启动

docker run -d --name r6t5 -p 8080:8080 \
  -v r6t5-data:/data \
  ghcr.io/tanchipanda/r6t5-docs-docker:latest复制

首次启动后查看日志里的管理员密码：

docker logs r6t5 2>&1 | grep -A2 "管理员"复制

也可以直接读数据卷里的文件：

docker exec r6t5 cat /data/ADMIN_PASSWORD.txt复制

docker-compose

services:
  r6t5:
    image: ghcr.io/tanchipanda/r6t5-docs-docker:latest
    ports: ["8080:8080"]
    environment:
      TZ: Asia/Shanghai
      # ADMIN_PASSWORD: 自定义管理员密码（可选）
      # SUPABASE_SERVICE_KEY: 可选，后台用户管理用
      # LICENSE_API: https://lic.r6t5.dpdns.org
    volumes: ["./data:/data"]
    restart: unless-stopped复制

后台能做什么（/admin）

  • 输入产品密钥，激活专业版（隐藏推广提示、署名可改）
  • 图形化编辑目录树（分组、顺序、标题、预览链接）
  • 在线编辑每一篇的文本与超链接，保存即生效
  • 按篇设置价格；配置积分 Supabase、VIP 档位、兑换码
  • 添加授权域名（走 DNS TXT 验证）与授权仓库

授权怎么生效

三种方式，任一满足即判定为专业版：

  • 产品密钥：后台「授权状态」输入 15 位密钥
  • 域名：后台添加域名 → 按提示在 DNS 加一条 TXT（_r6t5-verify.你的域名 = r6t5-verify=<token>），只看 TXT 值，不校验 A/CNAME
  • 仓库：后台填 owner/repo，该仓库的部署直接按专业版处理

站内右键菜单与 AI 对话

站点页面右键会弹出站内菜单：AI 对话 / 复制 / 纠错 / 属性 / 显示更多选项。AI 需要后端，这里用 Cloudflare Workers AI：

cd worker
npx wrangler login
npx wrangler deploy复制

部署后把地址填到 manifest.json 的 ai.endpoint（静态版）或后台「AI 接口地址」（Docker 版）。留空时该菜单项置灰，其余功能不受影响。Worker 源码见本仓库 worker/。

启动完整性门禁

容器启动时会比对站点文件与镜像原版的 sha256，并校验署名配置：版权被改过但未授权时直接打印差异并退出，不提供服务；已授权则只打印警告继续启动。运行期对被篡改且未授权的请求返回 503。

接入积分与 VIP

需要自己的 Supabase 项目，约 5 分钟。

1

建项目拿 key

在 Supabase 新建项目，Project Settings → API 复制 URL 与 anon key。

2

执行 SQL

SQL Editor 里依次整段执行 sql/points.sql 与 sql/points_v2.sql（可重复执行）。

3

后台填写

管理后台「文档积分」粘贴 URL 与 anon key，设置免费可读比例与默认价格，点「测试连接」。

4

发积分

兑换码批量生成，或执行 select public.r6t5_grant('用户UUID'::uuid, 100)。系统不提供人民币充值/提现。

常见坑

部署时最容易踩的几件事。

页面 404 / 空白

静态版要在仓库根目录放 index.html；Pages 的 Source 选 root，不是 /docs。

忘记管理员密码

数据卷里的 ADMIN_PASSWORD.txt 就是密码；删掉该文件重启会重新生成，但会注销已登录会话。

改了版权起不来

未授权时改了站点署名或页脚，启动会退出。要么改回，要么在后台激活授权。

积分不生效

URL 或 anon key 少了、SQL 没执行、文档价格为 0，三者任一都会让文档直接免费。
