内置能力

不是“能显示 Markdown”那么简单，是把运营文档站要用的东西都做进去了。

⌘K 全文搜索

标题与正文同时命中，方向键选择、回车跳转；付费文档只按标题命中，不泄露正文。

按篇定价

每篇单独设价格，0 或可读率 100% 自动免费；未解锁只放出设定比例。

账户与积分

站内邮箱注册即开积分账户，积分支付 VIP，仅对当前站点生效。

图形化后台

目录树、预览链接、全部文本与超链接、署名都能在后台改，不用改代码。

署名保护

社区版逐字符校验署名与「了解 Pro」入口，删改即还原；授权后可关闭提示。

授权可验证

产品密钥、DNS TXT 域名验证、授权仓库三种方式，按请求 Host 判定。

三分钟跑起来

想做静态站就 fork，想做收费站就起容器。

1

fork 社区版仓库

把 docs/ 换成你的 Markdown，改 manifest.json，推送即上线。

2

或者起一个自托管容器

数据卷挂出来，首启自动生成管理员密码。

docker run -d --name r6t5 -p 8080:8080 \
  -v r6t5-data:/data \
  ghcr.io/tanchipanda/r6t5-docs-docker:latest复制
3

在后台填授权与积分

打开 /admin，输入产品密钥，再填 Supabase URL 与 anon key，文档即可按篇计费。
